Recipe detail, S3b exit-from-cooking-mode snackbar (mobile)

Plan 0111 (S3b), R12; UI Designer decisions/0078. Exiting cooking mode with a timer lands on the recipe page and shows the house snackbar, no action, 8,000 ms, placed by the CURRENT page's rule: 8 px (FAB_SNACKBAR_GAP) above the house tab bar on phone and tablet. Web (owner decisions/0015): it is raised on the ONE app-wide snackbar host (U7a), so it outlives the page change; with the sidebar (>= 840) it is centred over the main column, never over the sidebar, 16 px above the bottom, at most 576 wide (Luna D21). The message wraps to as many lines as it needs and is never clamped (Luna D21). The snackbar never takes focus: focus goes to the page's h1. Its message is announced once, when raised. The running-timer dock drawn on RecipeDetailScrolled is S4 (decisions/0111), not built in S3; until then the snackbar sits above the tab bar.
