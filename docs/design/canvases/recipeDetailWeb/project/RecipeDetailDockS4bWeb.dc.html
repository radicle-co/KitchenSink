Recipe detail, S4b timer dock (web)

S4b. While the cook has a timer, every recipe page shows it in a dock: S3's CookingTimerRow inside a region named "Timer" (cooking.dock.region). It is not a live region, so the ticking clock is not announced. Below 840 px and on every native size the dock sits 8 above the tab bar, at most 600 wide and centred; on web at 840 and up it sits at the foot of the main column, never over the sidebar. The page keeps room at its foot for the dock's measured height, so the last step and every focused control end above it. Past one third of the window's height the dock moves into the page under Continue or Start cooking, and the page keeps no room for it; placement is decided on mount and on a size or text-size change, never on a state change. On the timer's own page the Continue line reads only the step: the dock alone carries the time. The step chips stay static (0111). In focus and reading order the dock follows the Continue or Start entry, wherever it is drawn.
