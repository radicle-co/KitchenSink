One at a time: the header's status line, in the words of this platform.

Saving: the draft is being written to this device.

Saved: the server has the draft as it is now.

Saved on this device: the device holds the draft; the server has not confirmed it yet.

A published recipe's change waits for Save changes.

Failed: the device could not keep the draft.

Retrying: the server write failed and is sent again.

Failed: the server write is parked. An alert offers Try again (see Save failed).

Unconfirmed: the server may or may not hold the write. An alert follows (see Save failed).
