## How to read this file

- **Lane** is who owns the row. The lanes are the lead (`main`), `architect`, `backend-prod`, `devils-advocate`,
  `feature-fab`, `native-ds` (the Tamagui design-system lane, Thing 1's work), `native-overlay`, `qa-device`, `docs`,
  the UI Designer session (`Designer`), and `Owner`. Lanes on new rows are the lead's first assignment. The lead
  changes them.
- **State** is one of: Open, In progress, Code done (needs a run), Done, Accepted, Decided, Dropped.
- Every row has both. The rows in the old PR 91 waves carry the state their text already named.
- Rules that bind every row: no UI is committed before the Designer says "approve". Nothing is pushed, merged or
  deployed without the owner's word. A skipped test is never a pass.

## Definition of done

1. Every UI change on the branch is approved by the Designer against the boards. Home, the Recipes card and Recipe
   detail are built to the boards BEFORE the merge (owner, 2026-11-02).
2. Every native screen and `@commise/ui` native component is styled with Tamagui, and the three ratchet baselines are at
   zero (owner goal, 2026-11-02).
3. The full Maestro suite passes locally on iOS and Android on the final head. The six paste-match flows are run, not
   listed as "not run" (row C3).
4. The full Playwright suite passes locally on the final head.
5. The `staff-code-quality` GATE passes over the branch, the branch is 0 behind `origin/main`, and CI is green on the pull
   request.
6. The owner merges, and approves the production deploy at the Production gate, after the queue is clear (row C1).
7. After the deploy, one real paste import and one recipe made in the editor both save in production on web, and the
   same two actions work on mobile (row M4 says how mobile reaches production).
8. Docs are settled: ADR-0080 is Accepted, this tracker is current, the parity audit is written, and the Designer's
   rulings file is current.
9. At the end, the six `test-local-*` Clerk users are deleted. The Mac tools (CocoaPods, libyaml, openssl@4, ruby) stay.
10. Nothing is left open except the items listed under "Kept for later on purpose".

The old PR 91 definition of done (green CI on PR 91, the 2026-10-24 merge) is met for PR 91 and is not repeated.
