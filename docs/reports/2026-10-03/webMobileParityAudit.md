# Web and mobile parity audit (2026-10-03)

**Purpose.** The owner ruled on 2026-10-03: "Mobile and web need to be checked, tested, and developed in lock-step."
This file lists each user-facing behaviour this effort changed. For each one, it puts the web tests beside the mobile
tests. It names every test that one platform has and the other lacks.

## How to read this

- **Scope.** The uncommitted delta on `chore/code-quality-enforcement-phase-1-2`: `git diff HEAD` plus untracked files.
- **Sources.** Plan 002 (S5 to S7, V1, V3, E1 to E3, N1). The curated catalog plan (U13 to U15, U21, U25). The design
  files `rowEditorOpenDecisions.md`, `v3Evaluation.md`, `compactHeightLayout.md` and `nativeContainerNames.md`.
- **No test ran for this audit.** Another agent runs Playwright and Maestro now. "Written" and "planned" mean the test
  exists and its runner picks it up. They never mean "passing".
- **The two device tiers prove different things.** Every Playwright spec here stubs the recipe and food services in the
  browser (`MOCK_MARKERS` in `PW/utils/specTier.ts`). Every Maestro flow drives the deployed sandbox of the pull
  request. So Playwright can show an outage or a slow answer. Maestro cannot.
- **Rules.**
    - A gap is owed. It is n/a only with a reason from a document, and the table cites that reason.
    - A test that never runs is a gap on its platform. This covers `test.fixme` and every flow in `KNOWN_UNRUN_FLOWS`
      (`packages/infra/global/__tests__/maestroFlowSelection.test.ts`).
    - A shared test (a pure `*.test.ts` or a hook suite) fills no platform column. The tables list it as "Shared".
    - An integration suite that renders a web leaf counts for web. Five do: `ambiguityReview`, `rowEditor`,
      `lookupRetry`, `ingredientNutrition` and `variantDetailsDialog`.
- **Cell format.** `C` is a component test, `P` a Playwright spec, `M` a Maestro flow. A file comes first, then its test
  titles, each in backticks and word for word. A Maestro cell gives the flow, then the step that proves the behaviour.
  A long title ends in `…`.
