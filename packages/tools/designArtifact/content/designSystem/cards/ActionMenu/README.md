ActionMenu puts a row's actions behind one ⋯ trigger. Items are caller-ordered with an optional icon, and the single destructive action is its own field, so it is always drawn last after a divider in the danger label. The web leaf is a Radix DropdownMenu with the full menu-button keyboard model; the trigger and each item are 44 px targets, and Escape returns focus to the trigger. The trigger label must name its row ("Actions for Tomato"), never a bare "More"; appearance="disc" draws the round control used over a hero photo, and unavailable keeps the trigger focusable but opens nothing. The native leaf is a bottom sheet of `menuitem` rows titled by `title` and closed by a control named `closeLabel`, which cannot obscure the row it acts on.
