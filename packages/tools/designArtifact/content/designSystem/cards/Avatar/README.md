Avatar is the profile entry: a 32 px disc that opens Profile. It shows a blank disc while loading, initials once ready, and a user glyph without a name or after a failed read. With an href it is a real link (a plain click goes to onPress, a modified click opens a new tab); without one it is a button. The label is its accessible name ("Profile, Ana Ruiz"), so always pass it. On native it is a Pressable button in a 44 pt target around the 32 pt disc.
