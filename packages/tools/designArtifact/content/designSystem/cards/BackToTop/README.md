BackToTop is a small secondary button with an up arrow that scrolls a long page to the top. It shows only on pages taller than four viewports, once the reader is more than four viewports down, and only while the last scroll was upward; it hides while the keyboard is open. After scrolling it calls onReturn so the host can move focus to the page H1. Set aboveFab to sit 16 px above a floating create button, and place it last in DOM order.

There is no native leaf: the source declares only the web component.
