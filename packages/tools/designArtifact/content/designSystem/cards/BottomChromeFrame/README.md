BottomChromeFrame decides who owns a native screen's bottom edge: whatever is bottom-most owns the safe-area inset. With no footer the frame pads the inset itself; with a footer, such as the bottom tab bar, the frame adds nothing and publishes the footer's measured height. The content is the frame's first child, so it keeps its node when the footer comes and goes, and the footer clears side insets itself. Pass the screen content as children and the footer as an element. It is native only.
