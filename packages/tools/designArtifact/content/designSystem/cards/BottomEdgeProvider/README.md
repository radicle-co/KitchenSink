BottomEdgeProvider publishes a bottom edge measured elsewhere, so popups clear the navigator's tab bar. A screen inside a tab sits above the bar, so its own frame has no footer to measure; popups opened in a modal window, such as the create dial's menu, read this value to stay above the bar. Pass `value` (the bar's height in points, including the safe-area inset) and the subtree as `children`. It draws nothing and has no accessible role. It is native only: web has no modal window that loses the page's insets. Mount it once around the tab navigator's screens.
