BottomSheetPanel is the native sheet's bottom-anchored skeleton: a title row with Close, an optional toolbar, a scroll region and a footer. It is native only; the web sheet's panel is SheetPanel, with different props. `size` is `content` or `full`, `focusSignal` moves screen-reader focus to the title each time the modal shows, and `reduceMotion` controls the swipe's snap-back. With a toolbar, an open keyboard collapses the title into the heading and hides the footer; the footer is pinned until it and the title row take over half the sheet, then it scrolls with the content. A downward swipe on the title row dismisses it, and it applies the device insets itself.
