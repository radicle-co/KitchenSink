CheckBoxGlyph is the 24 px box drawn at the start of a whole-row checkbox, such as a shopping-list item. Unchecked it is a 2 px outline; checked it fills with the action colour and the check springs in over 120 ms, a motion that reduced-motion turns off. It is hidden from assistive technology because the row it sits in is the checkbox. Never give it its own click handler or name. The native leaf draws the same box and the same spring-in check, also hidden from assistive technology.
