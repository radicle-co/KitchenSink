Chip is a pill for a facet or a value. A filter chip is a toggle button (aria-pressed) that shows a check while selected and an optional count; an input chip shows a value with a trailing x and is named by the caller's removeLabel ("Remove Vegan"). Labels over 24 characters show truncated while the full label stays the accessible name. Use filter chips to narrow results and input chips for values the person has added. On native a filter chip is a `checkbox` control and an input chip is a button named by `removeLabel`, with the same props.
