ChipRow lays out chips as a named row that either scrolls inside itself or wraps. In filter and input mode it is a labelled group around chips the screen places; in choice mode it owns its options and is a radiogroup with roving focus and arrow keys. Set clearable for a choice that can be pressed again to clear it (difficulty), which renders radios in a toggle group. Always give the row a label, since it is the group's accessible name. On native a scroll row is one horizontal line with a fade over its end while more chips lie beyond it, and choice mode is a radiogroup of radios with aria-checked.
