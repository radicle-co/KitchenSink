ChoiceRow is one row in a list of choices whose press is the choice, such as one food a matched ingredient line could be, or the quiet "Keep … as written" row. It is a button, not a radio: in a radio group the arrow keys would choose each row they land on. The row owns its states. When `chosen`, it draws a check after the label. When `busy`, a spinner replaces the check and the row refuses the press while its send is in flight. When `refused`, another row's send is in flight, so the row refuses the press but stays focusable on web. `children` is the label, usually an `OptionLabel`. `accessibilityLabel` must start with the visible label and say ", chosen" when the row is chosen. `focusRequested` asks for focus as a level, and the host clears it in `onFocusRequestHandled`. Every string is localised by the caller.
