ConfirmDialog confirms a destructive step with two verb buttons. It is a Radix AlertDialog with a title, body, a destructive confirm and a safe keep action, and focus opens on Keep. While busy the confirm spins and cannot fire again, and an error string is shown inside the dialog. Buttons stack full width below 400 px, destructive on top. Name the buttons with the verbs ("Delete recipe" and "Keep recipe"), never Yes and No. On native it is drawn in the design system's DialogFrame, with the buttons stacked and the Android Back button acting as Keep.
