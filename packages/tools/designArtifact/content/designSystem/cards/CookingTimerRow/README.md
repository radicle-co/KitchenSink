CookingTimerRow is one row for a cooking timer: a body, then the actions that fit its state. A running timer has Pause and Cancel, a paused one has Resume and Cancel, and a finished one has Stop. The caller passes every string, already localised. The row is not a live region. The body is usually a CookingTimerSummary: a timer glyph, the time (it never wraps), an optional status word and a meta line that wraps. The glyph hides above 1.3x text size so the time keeps its room.
