DialogFrame is the fixed chrome of a centred dialog on native: a modal window, a dimmed scrim padded into the safe area, the keyboard kept off the card, and a card whose content scrolls. It takes `open`, `onRequestClose` (Android Back; the scrim is not a dismiss route), `title`, `role` and `children`. The title is a header and takes screen-reader focus each time the window shows, and taps persist through the keyboard so the first tap on an action presses it. Use `role="alert"` only for a confirmation that interrupts. It is native only because the web dialogs are Radix's; the host supplies the body and the actions.
