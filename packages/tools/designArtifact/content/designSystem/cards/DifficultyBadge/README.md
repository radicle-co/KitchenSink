DifficultyBadge shows a recipe's stated difficulty as a tint, a three-dot meter and the word. Pass `level` as `easy`, `medium` or `hard`, which fill one, two or three dots, and give the localised word as `children`. The meter and the word carry the meaning, so it never relies on colour alone, and `error` is never used as a difficulty colour. The word is announced with the text the badge sits in. Always supply the word from your own localised copy, because the design system holds no message catalogue.

The native leaf draws the same tint, three dots and word.
