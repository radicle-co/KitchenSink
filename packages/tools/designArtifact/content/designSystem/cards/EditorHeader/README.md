EditorHeader is the 56-pixel top bar of the recipe editor: a close button, the title, a save status and an optional more-actions menu. The title is "New recipe" or "Edit recipe", never the recipe's own name, and it is the screen's heading. Pass `title`, `status` (or `undefined` when there is nothing to say yet), `closeLabel` and `onClose`; pass `menu` only when there is something to discard, and it holds the one destructive action. Closing never asks, because the editor saves by itself. The header sits on the solid page surface, since the editor's only glass is its action bar. It has a web leaf, which is sticky and can report its node for measuring, and a native leaf with the same props.
