EditorSection is one section of the recipe editor: a heading row with the section's own controls at its end, then the body. It takes `id`, `title`, an optional `action` for the heading row, `current` (whether the cook is in this section) and `children`. On web it is a region named by its H2, whose id is what the section index links to and the page's ScrollHost jumps to, and the heading takes DOM focus after a jump. On native, the heading takes the screen-reader cursor when `focusSignal` advances; web ignores that prop. Render each native section as a direct child of the scroller's content so it can report its layout.
