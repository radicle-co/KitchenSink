A wrapper that gives a section the brand enter gesture: a short rise and fade as it appears. `delayMs` staggers a run of sections. On web it is pure CSS, so content is never hidden before hydration, and under `prefers-reduced-motion: reduce` the animation is not emitted at all. Wrap the section that should enter; do not animate by other means. On native the same rise and fade runs through an Animated value, and nothing starts until the OS reduce-motion preference is known.
