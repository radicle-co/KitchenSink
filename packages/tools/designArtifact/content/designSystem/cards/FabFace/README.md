FabFace is the glyph and label drawn inside the floating create button. In the `extended` presentation the label shows beside the icon; in the `icon` presentation the label stays in the accessible name but is visually hidden. A hidden, out-of-flow twin of the label is measured and reported through `onLabelWidth`, so the button can decide whether the label fits in half the window. It is an internal part of CreateFab and is not meant to be used on its own. On native it draws seafoam-tinted Liquid Glass on iOS 26 and a solid action disc or pill elsewhere.
