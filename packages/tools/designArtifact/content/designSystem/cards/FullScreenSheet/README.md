FullScreenSheet is the design system's full-screen modal sheet, native only. It owns the modal window, its motion and the inset math: the content is padded 20 dp plus the device inset on every edge, so a heading never sits under the status bar nor actions under the navigation bar. Pass `onRequestClose` as the single dismissal path (Android back and the Cancel control should both call it), an optional `label` as the surface's accessible name, and `onShow` to move the reading cursor into the sheet. It slides in only when reduce motion is off. Consumers render their own heading and content; web uses Sheet instead.
