HeroButton is a single round 44 px control that sits over a recipe photo, used for the recipe page's Back and ⋯ buttons. It carries a glyph and never text, and its accessible name is `label`, which should never be a bare "Back" or "More". With an `href` it is a real link on web (so Back can open in a new tab); without one it is a button. It can report an open or closed state through `expanded`, which a menu trigger needs, and can be `disabled`. On web it is a solid photo-chip disc; on iOS 26 it is regular Liquid Glass.
On native it is a regular Liquid Glass disc on iOS 26 and a solid photo-chip disc elsewhere, and it ignores `href`.
