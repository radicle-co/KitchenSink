HomeSidebar is the web navigation sidebar at 840 px and wider, replacing the tab bar. Top to bottom it holds the wordmark, the New recipe control, the destinations, a divider, the profile row and the collapse control, 256 px expanded and 80 px collapsed. It takes the chrome copy, locale, live capabilities, the active destination, the profile read, collapsed, onToggleCollapse and a newRecipe node. Collapsed is a visual state only: each control keeps its accessible name, and a portalled tooltip shows the label. It has no native leaf; native navigates with the tab bar.
