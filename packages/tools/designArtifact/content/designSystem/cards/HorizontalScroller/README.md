HorizontalScroller is the one horizontal scroller of the app: chip rows, the recipe section bar and the browse rails all use it. Its scrollbar stays hidden until the reader scrolls (on web with a fine pointer it also shows while the pointer is over it). A decorative right-pointing chevron appears at the inline-end edge only while the content overflows and the scroller rests at its start; it goes on the first scroll and returns when the scroller is back at the start. A fade over the end shows while more content lies ahead. It mirrors in right-to-left, never takes a touch, and fades over 150 ms except under reduced motion. Give it a regionLabel to make it a focusable named region whose arrow keys move it by one item (list items); set snap to settle on items or cards; set surface so the native fade ends in the colour behind it. It reports where it rests through onPosition, and the web leaf hands its element to onScroller.
