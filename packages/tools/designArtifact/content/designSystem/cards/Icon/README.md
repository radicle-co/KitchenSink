Icon draws one glyph from a closed list of meanings, so a screen names a meaning such as `trash` and never a library glyph. `size` is 16, 20, 24 or 48 and defaults to 24; `tone` picks a colour role, otherwise the glyph inherits its text colour on web. Directional glyphs (`chevronLeft`, `chevronRight`, `chevronsLeft`) mirror in right-to-left layouts. Without a `label` the glyph is decorative and hidden from assistive tech, which is right whenever the control around it already has a name. Set `filled` only for the active tab. The native leaf maps the same meanings to Lucide glyphs in its own table, and with no `tone` it draws in `ink`, because a native glyph inherits no text colour.
