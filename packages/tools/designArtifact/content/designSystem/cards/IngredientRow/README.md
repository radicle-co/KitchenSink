IngredientRow is one row of the recipe editor's ingredient list. At rest it reads: the amount in a fixed column, then the name with its preparation after a dot, then a menu, and a second line only when the cook has something to do. The amount and name together are one control named Edit followed by the amount and food; a line with no food opens a food search in place of the name. It takes the row's view plus a panel for the attention line and the inline editor slot; native also takes the amount column width. A healthy row stays quiet, and a state is stated in text, never by colour alone.
