The "Screen on" switch that keeps the screen awake while the cook follows a recipe. It is a controlled `switch` with `aria-checked`: you pass `on`, `onChange` and a localised `label`, and the parent holds the one wake lock. `display` is `labelled` (visible text, from a 720 body) or `icon` (the sun glyph alone, in the section switch); the label is the accessible name in both. State never rests on colour alone, because the glyph fills while on. Where the browser has no Wake Lock API the toggle renders nothing rather than showing a disabled control. On native it is a `switch` drawn as the chip pill inside a 44 pt hit area, and it always renders because the capability is always there.
