KeyboardAvoider is the one keyboard rule for a screen or a modal's content, native only. It pads its content up by the part of it the keyboard covers, on iOS and on edge-to-edge Android alike, and takes only `style` and `children`. Place it in a box that starts at the top of the window: a screen's root, a padding SafeAreaView, or a modal's backdrop. It is the only module in the apps that renders React Native's KeyboardAvoidingView. On web the browser resizes the page, so there is no web leaf.
