LoadingNotice says what a region is loading when it has no settled shape to hold with a skeleton, such as the session check, the recipe editor or collection detail. Pass `label` as contextual localised text in the form "Loading ‹thing›…"; it is both the visible caption and the accessible name. The web leaf is a `status` region named by its caption with a decorative spinner; the native leaf is one accessible `progressbar` element, centred in the upper two thirds. Both enter after 400 ms through EnterTransition, so a load that ends quickly never flashes a spinner, and neither is a live region. Use it where a failed load will swap in a StateNotice in the same place.
