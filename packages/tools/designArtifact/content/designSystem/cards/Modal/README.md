Modal is the one React Native `Modal` the apps open, native only. It opens its window to every orientation, because iOS otherwise locks a modal to portrait, which fails WCAG 2.2 SC 1.3.4. On Android, a Back that arrives while a field's keyboard is open closes the keyboard only; the next Back closes the modal. It hands its contents a revealer that does nothing, so no scroller outside its window tries to reveal a field inside it. It takes React Native's `ModalProps` without `supportedOrientations`, and a raw `Modal` import from `react-native` elsewhere in the apps is refused by a guard test.
