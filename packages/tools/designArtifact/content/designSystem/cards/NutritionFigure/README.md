NutritionFigure shows one per-serving nutrition value on the recipe page, such as "32 g" over the label "Protein". It takes `label` (the figure's name) and `value` (the figure, per serving), and draws the value in the `figureStat` role over a `caption` label. On web it is a `dt`/`dd` pair, so it must sit inside the section's `dl`; on native it is half a row wide, so four make a 2 × 2 grid. It is presentational and takes its colours from the theme. Pass both strings already localised.
