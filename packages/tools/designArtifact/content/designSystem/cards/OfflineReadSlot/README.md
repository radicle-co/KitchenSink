The quiet line shown where a screen's content would be while its read is parked offline. It replaces the loading skeleton rather than sitting beside it, since a parked read is not loading. It is a `role="status"` region and has no retry control, because the read resumes on its own on reconnect. Pass a localised two-sentence `message` whose second sentence says the screen recovers by itself.

The native leaf is the same quiet line, without a live region, because the platform's only equivalent would interrupt the screen reader.
