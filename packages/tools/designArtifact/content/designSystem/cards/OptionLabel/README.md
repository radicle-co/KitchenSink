OptionLabel is the label of one option in a list of choices: its name, an optional quiet tag after it (the "Default" in the food picker and the matching lists), and an optional line of a variant's parts under it. It only displays. The option that holds it owns the role, the accessible name and the press, and a tagged option's accessible name must say the tag. `textSize` is required: `list` sets the 14 px list role for a line in a list of choices, and `bodyMd` sets 16 px for a combobox option, so it matches the field the cook types in. The parts line is 14 px at either size. Every string is localised by the caller.
