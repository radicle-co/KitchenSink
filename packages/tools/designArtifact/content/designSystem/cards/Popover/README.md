A small panel that its own trigger opens by activation only, with no hover. On web it is a non-modal dialog anchored to the trigger, flipping to stay on screen; Escape and Close return focus to the trigger. `triggerLabel` must name what the panel is about, never a bare "More", and `triggerText` adds visible attention words that the label must contain. `busy` shows a spinner in the glyph's box and sets `aria-busy` while keeping focus. `children` may be a function that receives `close`. On native the panel is the design-system Sheet, opened by a tap from a 48 by 48 dp trigger, and the screen-reader cursor returns to the trigger when it closes.
