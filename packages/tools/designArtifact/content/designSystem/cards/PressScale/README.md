PressScale gives a control a tactile "shrink while held" press scale that respects the OS reduce-motion preference. On web it is a presentational span wrapping the interactive child (a button, a linked card, the floating action button); the child keeps all press semantics and accessibility, and PressScale contributes only the motion. The `width` prop is `auto` (hug the child, the default) or `fill` (stretch across the parent). Under `prefers-reduced-motion: reduce` no transform or transition is emitted, and a child marked `aria-disabled` plays no scale. Wrap the element that should scale and attach `onPress`, labels and roles to that child, because the web leaf ignores those props. On native it renders the Pressable itself, so onPress, disabled, busy, accessibilityLabel and accessibilityRole are honoured, and the scale is suppressed when disabled or when reduce motion is on.
