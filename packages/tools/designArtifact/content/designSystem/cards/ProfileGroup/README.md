ProfileGroup is a grouped list of Profile rows, the settings-list pattern of the account page. Pass `heading` for a visible H2, or `label` for a group with no visible heading; the group is then a named region on web, so a screen reader can jump between groups. The card clips its rows to the radius and draws a hairline between them. On native the heading is a header-role Text and colours come from the theme. Fill it with ProfileRow children.
