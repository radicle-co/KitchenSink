ProfileRow is a pressable Profile page row, 56 px tall, with a label, an optional one-line value, an optional hint and a chevron when it opens something. The whole row is the control: the label names it and the value and hint are read after the name. `tone` is `ink` or `danger`, and danger changes the text colour only; sign out is `ink`. While `busy` the row cancels the press and stays focusable, and an `inert` row (its action is done) ignores presses without dimming. On web a row can take an `href` so a modified click still opens a new tab; on native `focusSignal` returns the screen-reader cursor to the row when its sheet closes.
