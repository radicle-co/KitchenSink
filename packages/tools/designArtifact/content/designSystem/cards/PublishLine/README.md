PublishLine is the Ready line of the editor's Photos and publish section, always shown for a draft so the cook can read whether Publish will go through. Its `line` is either `ready`, drawn as plain text, or `fix`, drawn as a ghost button with a warning glyph that calls `onJump` with the first section that needs work. The action bar's polite line is the one that announces, so this line is not a live region. The native leaf has the same props. Show it for a draft only; a published recipe has no Ready line.
