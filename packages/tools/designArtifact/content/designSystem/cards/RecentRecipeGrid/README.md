RecentRecipeGrid is Home's Recent recipes arrangement: a fixed grid, 2 x 2 below a 600 container and one row of four from 600, of recipe cards in the variant the host decided. It takes recipes, variant, onSelectRecipe, an optional hrefOf and an optional renderNutrition, and it owns the arrangement and nothing else. On web hrefOf makes each card a real link; native ignores it and reads the window width. Let the host decide the variant (compact below 960, the full card from 960) and pass it in.
