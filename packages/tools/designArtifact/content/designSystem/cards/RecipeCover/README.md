RecipeCover shows a recipe's photo, or its monogram when the recipe has none. The `aspect` prop reserves the box so nothing shifts as an image loads: `4:3` card, `1:1` thumbnail, or `band` (the 96 px strip across a phone's detail hero). Without a `photoUrl` the monogram uses a tint picked by `recipeId`, so a recipe looks the same everywhere, plus the title's first letter and, on covers 96 px tall or more, the cuisine as an overline; pass `overline={false}` when a chip sits over the cover. The cover is decorative (empty `alt`, monogram hidden) because the title names the link it sits in. Always pass the stable recipe id so the tint does not change between views.

The native leaf draws the photo through expo-image and measures its own height to decide whether the cuisine overline shows.
