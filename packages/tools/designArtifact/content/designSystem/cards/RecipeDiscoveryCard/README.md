RecipeDiscoveryCard is a Discover result: the shared RecipeCard with the Discover footer, which holds the author or source and the Save a copy icon button. The host decides `variant` (`grid` from a 600 container, `compact` below) and `headingLevel` (2 for results, 3 under a rail heading), and passes the card model, `saveCopy` state (`idle`, `saving`, `saved` or `failed`), `onSelect` and `onSave`. The whole card is one link on web, named by the title, and the Save control sits above it and is never nested in it. While a copy is saving or saved the button is inert but stays focusable on web, and a failure shows an inline alert. The native leaf has the same props, minus `href`.
