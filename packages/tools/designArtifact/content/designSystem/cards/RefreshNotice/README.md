RefreshNotice reports that refreshing data already on screen failed, so the rows the person is reading may be out of date. It takes `failed` and `refreshing` flags (from the query's refetch-error and refetching state), an `onRetry` handler and localized `labels` for the message and the retry button. While nothing has failed it renders only an empty polite `status` region, so a failure is announced when its text appears. A retry in flight keeps the message and the same busy button, so focus is not dropped (WCAG 2.2 SC 2.4.3). Use it only when data is loaded and a refresh failed; a read that failed with nothing loaded is the surface's own error state.

On native a polite, visually hidden LiveRegion speaks the failure, and the retry button stays the same button while a retry is in flight.
