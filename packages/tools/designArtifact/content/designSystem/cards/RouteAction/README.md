RouteAction is a web control that goes somewhere: a real link when it has an `href`, so open-in-new-tab works, and a button when it has none. A plain click cancels the link's own navigation and calls `onPress`, so the app's router moves; a modified click (new tab, new window) is left to the browser. It takes an optional `label` (the accessible name; without one the children name the control), `onPress`, `className` and children, and draws no styling of its own. It is internal to the design system, used by the avatar and back controls. Always give it a `label`, since its children are usually an icon or image.
It has no native leaf, because native has no URLs and its controls are plain presses.
