SearchField is the one pill-shaped search input (48 px tall, `type="search"`) with a leading search glyph. It always has a label, either drawn above it (`labelVisibility="visible"`) or visually hidden but still its accessible name; a placeholder is only an example query, never the label. It is controlled through `value` and `onChangeText`, with optional `onSubmit`, `onFocus` and `onBlur`. A non-empty field shows a 44 px clear control named by the caller-supplied `clearLabel`, and clearing returns focus to the field. The design system holds no copy, so pass localized `label` and `clearLabel`. On native it is a 48 pt pill with a 44 pt clear control, the OS clear button off and the return key saying search.
