SectionIndex lists a long form's sections with a status for each, in one of three presentations chosen by the width of the main container: a 240 px sticky rail at 960 and up, a one-row strip from 600 to 959, and a one-line bar that opens a sheet below 600. Each item has a `label`, a `tone` (`fix`, `attention`, `muted` or `complete`, never colour alone: each has a glyph or words), an optional `reason`, `count` and `hint`, and `currentId` marks the reader's place with `aria-current`. It knows nothing about recipes; the caller supplies all localized copy, including `barName`, `sheetTitle` and `sheetCloseLabel`. Jumps go through the screen's single ScrollHost, so render it inside one and place it as a direct child of the box it should stick in.

On native the window's width class picks the presentation, a row's reason reaches a screen reader as its hint, and the caller moves accessibility focus to the heading in `onJump`.
