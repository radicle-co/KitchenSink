The skeleton inside the web Sheet: the title row with Close, an optional toolbar, the scroll region and the footer. It must render inside a Radix Dialog, so use `Sheet` rather than mounting it alone. With an on-screen keyboard open and focus in the toolbar controls, the title is visually hidden but still names the dialog, the heading moves into the title row, and the footer hides. Close and the controls never change place in the tree, so focus survives. The footer is pinned until it and the title row take more than half the sheet, then scrolls with the content. It has no native leaf: the native sheet builds the same skeleton in BottomSheetPanel and FullScreenSheet.
