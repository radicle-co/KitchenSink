Spinner is the 20 px in-flight arc, internal to the design system: Button draws it in its busy slot and LoadingNotice draws it beside its caption. It takes one prop, `className`, which carries the spin animation and any text colour, because the arc itself inherits `currentColor`. It is hidden from assistive technology, so whoever draws it carries the meaning, through `aria-busy` or a caption. Spin it always inside a control and only under `motion-safe:` beside a caption. It has no native leaf: native uses the platform ActivityIndicator.
