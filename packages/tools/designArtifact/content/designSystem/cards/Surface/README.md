Surface is the container that states which surface its content sits on: `canvas` (the page), `paper` (a card), `paperOverlay` (a sheet, dialog or menu) or `muted` (a quiet panel). It paints that fill and tells every control inside it, so a pressed button gets a fill that still shows on that surface and a chip rests on a fill that differs from it (paper on `muted`, muted elsewhere). State a tone once, on the element that paints the fill. A container that states nothing inherits the tone above it, and a popup root states its own because a portal leaves the tree. On native the same `tone` prop sets the context the controls read.
