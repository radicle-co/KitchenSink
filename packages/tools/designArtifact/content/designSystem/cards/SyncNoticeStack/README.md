SyncNoticeStack is the column that the sync and unreadable-work notices sit in. Its only prop besides `children` is `active`, which says whether any notice is showing. On web it draws nothing: the notices flow at the top of main. On native it is an in-flow column that takes the top safe-area inset only while `active`, and it is never absolute, so the screens below get less height and nothing is clipped. Put it above the navigator and give it SyncNotice and UnreadableWorkNotice as children.
