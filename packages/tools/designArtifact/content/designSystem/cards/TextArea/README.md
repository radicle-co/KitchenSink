TextArea is a multi-line text field that grows with its content. `minRows` sets the starting height in lines and `maxRows` the point where it stops growing and scrolls; without `maxRows` it grows without bound. It is controlled through `value` and `onChangeText`, and supports `invalid`, `describedBy`, `disabled` and `placeholder` like Input. It draws no label of its own, so pair it with a FieldLabel by id. Use it for method steps, notes and descriptions.
The native leaf grows the same way from `minRows` to `maxRows`, takes `label`, `hint` and `error` itself for the screen reader, and holds the field in view while the keyboard is up.
