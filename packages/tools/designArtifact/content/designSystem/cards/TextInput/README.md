TextInput is the one React Native TextInput the apps render. It fixes disableFullscreenUI on every field, so Android never hands a focused field a full-screen editor that hides its label and context, and it takes that prop out of the API. Every other prop passes through, ref included. A field with a nativeID registers itself so the FieldLabel naming that id focuses it when pressed. Always import it from the design system rather than from react-native. It is native only; the web uses Input and TextArea.
