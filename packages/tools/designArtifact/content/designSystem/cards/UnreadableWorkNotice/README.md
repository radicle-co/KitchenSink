UnreadableWorkNotice reports a past event, that saved work could not be read, and carries a Dismiss control. It takes shown, title, body, dismissLabel and onDismiss; the caller owns whether the card shows, and the region around it is mounted either way so the change is announced politely. On web, focus lands on the region when the card leaves; on native no focus move is made, because React Native cannot read where the screen-reader cursor is. Use SyncNotice for an ongoing condition that has nothing for the viewer to do.
